# HTML 页面

用户点名要页面时，用本机的 answer-me-with-html 来做：你只写一份 Markdown 稿件，它的命令行工具负责排版、配色和画图。不要自己手写 HTML、CSS 或 SVG。

它装在 `~/.local/share/answer-me-with-html/skills/answer-me-with-html/`。先读这个目录里的 `SKILL.md`，照它写稿和渲染；它文中的 `${CLAUDE_SKILL_DIR}` 换成这个目录。这个文件不存在时，告诉用户这台机器没装，然后用文字回答。

下面两条和它写的不一样，以这里为准：

- **什么时候出页面**：只在用户这一次明确要求时出。它第 1 节的判断条件和 always-on 模式都不适用。之后的回合用户没再要求，就照常用文字回答，问题再复杂也一样。
- **文字回复**：它要求只回 2–3 行，这里要写得更全：先写核心结论，再把每个面板的要点各用一两句话写出来，最后一行是页面链接。图表不用在文字里重画。原因是 learn 的记忆整理和聊天搜索只读得到文字回复，读不到页面里的内容。
